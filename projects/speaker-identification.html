VoxCeleb speaker identification

Closed-set speaker identification across 605 voices using a VGG16-Lite-inspired 2D CNN.

  • PyTorch
  • CNN
  • Mel spectrograms
View repository ↗Public repository

01 / MOTIVATION

Why this problem?

Speech carries information about the person speaking as well as the words being said. This project investigates how a convolutional model can learn those distinguishing patterns.

02 / THE NEED

What needed to be addressed.

Identify speakers from spectrograms across a large, fixed set of known identities, with a repeatable training and evaluation workflow.

03 / THE SOLUTION

How it was approached.

  • Designed a VGG16-Lite-inspired 2D CNN with batch normalization and dropout for speaker classification.
  • Trained on augmented Mel spectrograms, using frequency/time masking, Gaussian noise, and circular shifts.
  • Evaluated 605 known speaker classes using validation accuracy and F1, with checkpoint selection and training-curve analysis.

04 / OUTCOME & CONTEXT

86.60% best validation accuracy

72,766 spectrogram samples · best checkpoint at epoch 45.

Interpreting the work

Validation clips are split at the file level, not grouped by recording session. No unknown-speaker verification, independent test result, or raw-audio preprocessing pipeline is demonstrated. The trained checkpoint is not yet included.
