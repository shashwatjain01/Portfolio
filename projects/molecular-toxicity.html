GRAPH NEURAL NETWORKS

Molecular toxicity prediction

Representing molecules as graphs to predict activity across 12 toxicity assays.

  • PyTorch Geometric
  • GCN
  • Tox21
View repository ↗Public repository
IN THIS PROJECT

01 / MOTIVATION

Why this problem?

Molecular structure contains relationships that are difficult to capture with flat feature tables. This project explores learning directly from atoms and bonds.

02 / THE NEED

What needed to be addressed.

Predict activity across multiple toxicity assays while accounting for missing labels and the connected structure of each molecule.

03 / THE SOLUTION

How it was approached.

  • Three graph convolution layers with 128 hidden channels and global mean pooling.
  • Adam optimization, learning-rate scheduling, checkpointing, and early stopping.
  • Visual analysis of assay performance, missing labels, molecular graphs, and learned embeddings.

04 / OUTCOME & CONTEXT

0.7705 mean validation ROC-AUC

7,823 molecules · 80/20 random training/validation split. ROC-AUC is not an accuracy percentage.

Interpreting the work

No scaffold split or independent test set. The notebook’s new-SMILES inference uses a different feature encoding from training; its example toxicity scores are not validated predictions.
